# Joguinhos em Python 🎮🐍

Este repositório reúne pequenos jogos e projetos que desenvolvi por diversão enquanto praticava programação com Python. Todos rodam no terminal ou em notebooks e foram feitos com foco no aprendizado e na criatividade.

## Jogos disponíveis

- **[Acerte o País](https://github.com/WevertonVerica/Streamlit)**: tente adivinhar o país com base em dicas!
- **Tabuleiro de Galton**: simulação visual do famoso experimento de distribuição normal.

Sinta-se à vontade para explorar, clonar e sugerir melhorias :)
